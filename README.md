## Featured

* **[DiGi.Core](https://github.com/ZiolkowskiJakub/DiGi.Core)** — foundation of the DiGi suite: domain models, serialization, and the reference system every other library builds on.
* **[DiGi.Geometry](https://github.com/ZiolkowskiJakub/DiGi.Geometry)** — 2D/3D geometry engine: boolean operations, meshes, polyhedra, point clouds.
* **[DiGi.GIS](https://github.com/ZiolkowskiJakub/DiGi.GIS)** — turns national GIS data (CityGML, BDOT10k, OpenStreetMap) into analysis-ready building models.
* **[DiGi.Solar](https://github.com/ZiolkowskiJakub/DiGi.Solar)** — solar irradiance and shading analysis over city-scale models.
* **[DiGi.GLTF](https://github.com/ZiolkowskiJakub/DiGi.GLTF)** — glTF export and a three.js viewer for delivering BIM models in the browser.
* **[HoareLea/SAM](https://github.com/HoareLea/SAM)** — Sustainable Analytical Model, an open-source building-performance framework I contribute to.

## 🧩 The DiGi suite

66 open-source C# libraries for BIM and CAD integrations, grouped by layer:

* **Foundational** — [Core](https://github.com/ZiolkowskiJakub/DiGi.Core/wiki) · [Math](https://github.com/ZiolkowskiJakub/DiGi.Math/wiki) · [Unit](https://github.com/ZiolkowskiJakub/DiGi.Unit/wiki) · [Log](https://github.com/ZiolkowskiJakub/DiGi.Log/wiki)
* **Geometry & graphics** — [Geometry](https://github.com/ZiolkowskiJakub/DiGi.Geometry/wiki) · [GLTF](https://github.com/ZiolkowskiJakub/DiGi.GLTF/wiki) · [Rhino](https://github.com/ZiolkowskiJakub/DiGi.Rhino/wiki)
* **GIS & data** — [GIS](https://github.com/ZiolkowskiJakub/DiGi.GIS/wiki) · [OSM](https://github.com/ZiolkowskiJakub/DiGi.OSM/wiki) · [BDOT10k](https://github.com/ZiolkowskiJakub/DiGi.BDOT10k/wiki) · [CityGML](https://github.com/ZiolkowskiJakub/DiGi.CityGML/wiki)
* **Simulation** — [Analytical](https://github.com/ZiolkowskiJakub/DiGi.Analytical/wiki) · [Solar](https://github.com/ZiolkowskiJakub/DiGi.Solar/wiki) · [Tas](https://github.com/ZiolkowskiJakub/DiGi.Tas/wiki)

Each repository carries its own wiki with architecture notes and generated API documentation.
